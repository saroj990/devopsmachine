# DevOps Learning Platform

Self-paced DevOps course for beginners: markdown lessons, hands-on labs, quizzes, and local progress tracking.

## Stack

- React + Vite + TypeScript
- Tailwind CSS
- React Router
- Markdown + Mermaid

## Quick start

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (typically http://localhost:5173) and start with **Beginner → Introduction to DevOps**.

## Production build

```bash
npm run build
npm run preview
```

Deploy the `dist` folder to Vercel or Netlify (SPA fallback is configured).

## Content

Beginner lessons live under `src/content/beginner/`. Register new lessons in `src/data/beginnerCourse.ts`.
